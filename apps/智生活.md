# 智生活 App 網路流量分析報告

## 概述

本報告依據 SRTT 與封包擷取工具分析**智生活**（`chp.kingnet.ios`）App 的網路請求。此 App 由 **SmaDay Technology Co., Ltd.（今網智慧／智生活）**提供，為**智慧社區生活平台**，功能包含社區公告、包裹與訪客通知、繳費、社群、生活資訊等，涉及**住戶身分與社區居住資料**。

本報告有兩項顯著發現：(1) 智生活雖為台灣品牌、處理社區住戶資料，但其**自家後端完全託管於 Google Cloud 公有雲（非台灣自建機房）**；(2) 本 App 整合了**本系列中最龐大的第三方追蹤堆疊**——含 **Microsoft Clarity（行為側錄／session 側錄）**、**Smadex（程式化廣告 DSP）**、Google／Facebook 廣告與分析、Bing、Infobip（德國）簡訊等。

```

  └─→ Facebook (Meta Anycast：tpe1 台灣／lax3 美國)
```

## 摘要

| 分類 | 網域 | 是否核心功能 | 連線節點 | 資料是否出境 |
|------|------|--------------|----------|--------------|
| 自家後端 | `*.kingnetsmart.com.tw`／`*.smartdaily.com.tw` | 是 | **台灣（GCP 邊緣；IP 註冊美國）** | **是（公有雲託管）** |
| Firebase／推播 | `firebaseio.com`／`googleapis.com` | 是（輔助） | 台灣（GCP／Google Anycast） | 是 |
| 行為側錄（Clarity） | `*.clarity.ms` | 否 | 台灣／日本／新加坡／美國 | 是 |
| 廣告與追蹤 | Smadex／Google／Bing／Meta | 否 | 台灣／美國 | 是／可能 |
| 簡訊／監控 | `infobip.com`／`sentry.io` | 是（輔助）／否 | **德國**／台灣（GCP） | 是 |

智生活是一款**智慧社區生活平台**，處理**住戶身分與社區居住資料**。與台灣政府／公營 App 將資料留在境內（GSN／HiNet）截然不同，智生活的**自家後端（會員、聊天、通知、訂閱、內容、MQTT）完全託管於 Google Cloud 公有雲**（mtr 443 連線節點在台灣邊緣，惟 IP 註冊美國、非自建機房），僅 `img.smartdaily.com.tw` 一個圖片網域在台灣 HiNet。

更值得注意的是，本 App 整合了**本系列迄今最龐大、最高強度的第三方追蹤堆疊**：**Microsoft Clarity 的 session 行為側錄**（可重播使用者操作）、**Smadex 程式化廣告 DSP**、Google／Bing／Facebook 之廣告與分析，以及 Infobip（德國）簡訊。對一款承載社區住戶資料的生活平台而言，此追蹤範圍相當可觀。
